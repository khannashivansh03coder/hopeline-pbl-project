Donor Hash Table with Collision Chaining

Average O(1) Lookup Complexity

Donors are hashed into fixed buckets indexed by blood group. Each bucket contains a linked list of donor objects for rapid retrieval during high-severity emergency calls.

Priority Queue (Max-Heap) Algorithm Specifications

O(log n) Insert & Extract-Max
1. Priority Score Formula

Score = (Severity × 5) + (Risk × 3) + (min(Wait / 5, 10) × 2)

Guarantees that severe emergency patients take precedence, while preventing starvation through the dynamic waiting-time booster factor.

2. Binary Heap Invariant

Parent(i) = ⌊(i - 1) / 2⌋
Left(i) = 2i + 1 | Right(i) = 2i + 2

Implemented using standard STL container backing with custom heapifyUp() and heapifyDown() routines in C++.

3. Donor Match Formula

Score = Compat(50/40) + Avail(20) + (20 - Dist/5) + Urgency/10

Multi-criteria heuristic optimization returning the single closest, eligible compatible donor in real-time.

Project-Based Learning (Phase-III)

HopeLine: Smart Hospital Resource and Blood Donor Matching System

During hospital mass-casualty emergencies, simultaneous manual tracking of beds, ICU capacity, oxygen supplies, and compatible blood donors causes critical delays. HopeLine combines real-time priority scoring, Max-Heap emergency queueing, and Hash Table donor matching into one cohesive decision-support system.
