Academic PBL Course Concepts Integration

Curriculum Mapping: Data Structures in C & OOPs with C++

HopeLine directly implements the requirements of both semester-3 courses in a single integrated healthcare decision platform under the mentorship of Mr. Sanjeev Kukreti.

Course 1: Data Structures in C
  • Binary Max-Heap: Custom heapifyUp() and heapifyDown() for $O(\log n)$ triage enqueuing and dequeuing.
  • Hash Table with Chaining: $O(1)$ average time donor lookup using linked buckets indexed by blood group.
  • Queue / Linked List: Overflow management for waiting patients.
Course 2: OOPs with C++
  • Inheritance & Polymorphism: Abstract base class Resource with derived ICUBed, GeneralBed, and OxygenUnit.
  • Encapsulation: Private data members with clean getters and setters.
  • Data Persistence: JSON file loading and saving via nlohmann/json.
