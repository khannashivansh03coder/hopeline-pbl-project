Donor Hash Table with Bucket Chaining

Average O(1) Lookup Complexity

Donors are hashed into fixed buckets indexed by blood group. Each bucket contains a linked list of donor nodes for instant retrieval during medical emergencies.

Mathematical Formulations in C++ Engine

1. Priority Score Formula

Score = (Severity × 5) + (Risk × 3) + (min(Wait / 5, 10) × 2)

Weights emergency severity highest, with dynamic wait time boosting to guarantee no patient starves in the queue.

2. Binary Heap Invariant

Parent(i) = ⌊(i - 1) / 2⌋
Left(i) = 2i + 1 | Right(i) = 2i + 2

Implemented using standard vector backing with custom heapifyUp() and heapifyDown() routines in C++.

3. Donor Compatibility Match

Score = Compat(50/40) + Avail(20) + (20 - Dist/5) + Urg/10

Multi-criteria optimization matching compatible blood types with geographic proximity and current availability.
